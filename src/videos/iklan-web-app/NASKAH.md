# NASKAH — iklan-web-app

- **Brand:** Youcanbuild (dibaca "yu ken bild")
- **Tujuan:** iklan jasa pembuatan aplikasi web untuk operasional kantor/perusahaan → konsultasi gratis.
- **Target penonton:** pemilik usaha & manajer operasional, 25–50 tahun.
- **Pesan utama:** kalau kantor masih rekap manual, saatnya punya aplikasi web sendiri — konsultasinya gratis.
- **Durasi:** ±30 detik (VO final 31,3 dtk), vertikal 9:16, TikTok.
- **CTA:** "Konsultasi sekarang juga" (gratis).
- **Bukti:** tangkapan layar asli dari repo portofolio `youcandbuilds` (Pracaya, Wisma Avicenna, dll.).

## Naskah (VO)

| # | Baris | Bagian |
|---|-------|--------|
| 1 | Tiga tanda kantor Anda sudah butuh aplikasi sendiri. | Hook |
| 2 | Satu: laporan masih direkap manual tiap akhir bulan. | Masalah |
| 3 | Dua: data penting tercecer di Excel dan chat WhatsApp. | Masalah |
| 4 | Tiga, yang paling sering diabaikan: tim sibuk, tapi kerjaannya itu-itu lagi. | Masalah (puncak) |
| 5 | Kalau satu saja kena, saatnya pakai aplikasi web yang dibuat khusus untuk kantor Anda. | Solusi |
| 6 | Seperti sistem laporan outlet dan aplikasi manajemen kos yang sudah kami bangun di Youcanbuild. | Bukti |
| 7 | Konsultasinya gratis. Konsultasi sekarang juga. | CTA |
