# NASKAH — dealer-pakaji

- **Brand:** Youcanbuild (penutup). Website yang dijelaskan: Dealer Pak Aji (portofolio, repo `strongerEv/dealerpakaji`).
- **Tujuan:** explainer: website itu tentang apa dan fungsinya untuk apa.
- **Target penonton:** pemilik dealer / showroom mobil bekas yang jualan lewat status & chat (TikTok/Reels).
- **Pesan utama:** stok tampil rapi 24 jam, pembeli bisa cari, hitung kredit, dan booking lewat WhatsApp; admin kelola stok & prospek.
- **Durasi:** ±43,6 dtk (VO 42,06 dtk + ekor), vertikal 9:16.
- **Bahan:** screenshot asli website (dijalankan lokal, layar HP 390×844 @3x). Pesan WhatsApp = teks asli buatan website.
  Prospek di panel admin = data contoh (nama fiktif). Tampilan status & chat WhatsApp digambar generik tanpa logo.
