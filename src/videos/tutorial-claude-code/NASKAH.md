# NASKAH — tutorial-claude-code

- **Brand:** Youcanbuild (penutup)
- **Tujuan:** tutorial singkat 5 langkah membuat aplikasi web dengan Claude Code, sampai online.
- **Target penonton:** kreator/pemilik usaha yang tidak bisa ngoding, 18–40 tahun (TikTok).
- **Pesan utama:** tanpa jago ngoding, kamu bisa punya aplikasi web sendiri lewat Claude Code.
- **Durasi:** ±40 detik (VO final 41,2 dtk), vertikal 9:16.
- **Fakta yang dicek (Okt 2026):** Claude Pro mulai US$20/bulan (belum pajak), sudah termasuk Claude Code;
  Claude Code di web menghubungkan GitHub; Vercel/Netlify men-deploy otomatis dari repo GitHub.
- **Catatan:** tanpa logo merek pihak lain (nama layanan ditulis sebagai teks).

## Naskah (teks layar memakai ejaan asli; VO memakai ejaan bunyi)

| # | Baris |
|---|-------|
| 1 | Mau bikin aplikasi web sendiri, tapi nggak jago ngoding? Ini lima langkahnya pakai Claude Code. |
| 2 | Satu: langganan Claude. Paket Pro mulai dua puluh dolar sebulan, sudah termasuk Claude Code. |
| 3 | Dua: bikin akun GitHub, lalu hubungkan ke Claude Code. Di sinilah semua kode aplikasimu disimpan. |
| 4 | Tiga: ceritakan aplikasimu pakai bahasa sehari-hari. Claude yang menulis kodenya. |
| 5 | Empat: sambungkan GitHub ke Vercel, Netlify, atau layanan deploy lainnya. |
| 6 | Lima: setiap kode yang masuk ke GitHub otomatis tayang. Aplikasimu online, bisa dibuka lewat link. |
| 7 | Simpan video ini. Mau dibantu bikin? Konsultasi gratis di Youcanbuild. |
