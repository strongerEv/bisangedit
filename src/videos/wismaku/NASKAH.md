# NASKAH — wismaku

- **Brand:** Youcanbuild (penutup). Aplikasi yang dijelaskan: Wismaku — manajemen kos (repo `strongerEv/wismaku`,
  di aplikasinya tertulis "Wisma Avicenna").
- **Tujuan:** explainer dengan sudut cerita (pemilik kos nagih sewa pintu ke pintu) + CTA konsultasi gratis.
- **Durasi:** ±46,3 dtk (VO 44,79 dtk + ekor), vertikal 9:16.
- **Gaya:** biru tua malam + kuning lampu + coral — sengaja tidak hijau. Pembuka: stickman mengetok pintu kos.
- **Bahan:** screenshot asli mode demo dari repo (`docs/screenshots`, data contoh).
