# NASKAH — tutorial-codex

- **Brand:** Youcanbuild (penutup). Part 2 dari tutorial-claude-code.
- **Tujuan:** tutorial 5 langkah membuat aplikasi web dengan Codex dari ChatGPT, sampai online.
- **Target penonton:** kreator/pemilik usaha yang tidak bisa ngoding, 18–40 tahun (TikTok).
- **Pesan utama:** dengan ChatGPT Plus + Codex + GitHub + Vercel/Netlify, aplikasi web bisa online tanpa ngoding.
- **Durasi:** ±50 dtk (VO final 49,9 dtk), vertikal 9:16.
- **Fakta yang dicek (Okt 2026):** ChatGPT Plus US$20/bulan (belum pajak) sudah termasuk Codex (termasuk cloud);
  Free/Go tanpa fitur cloud. Codex web: hubungkan GitHub di chatgpt.com/codex, pilih repo, beri tugas, cek diff,
  buka pull request, gabungkan. Vercel/Netlify men-deploy otomatis dari repo GitHub.
- **Catatan:** tanpa logo merek pihak lain (nama layanan ditulis sebagai teks).

## Naskah (teks layar memakai ejaan asli; VO memakai ejaan bunyi)

| # | Baris |
|---|-------|
