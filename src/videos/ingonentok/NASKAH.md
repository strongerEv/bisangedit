# NASKAH — ingonentok

- **Brand:** Youcanbuild (penutup). Website: ingonentok — company profile + katalog harga peternakan entok
  (repo `strongerEv/ingonentok`, statis HTML/CSS/JS).
- **Sudut:** "etalase online untuk peternak" — dari ditanya harga satu-satu di chat ke katalog + pesan WA otomatis.
- **Durasi:** ±52,9 dtk (VO 51,35 dtk + ekor), vertikal 9:16.
- **Warna:** dasar PUTIH (seragam antar video) + aksen hijau/kuning dari logo (#1E5B2F, #7CB342, #F7C948).
- **Bahan:** screenshot asli website (dijalankan lokal, 390×844 @3×), termasuk 8 frame animasi rombongan entok
  di beranda, kartu 6 produk, form pesanan cepat (diisi data contoh "Pak Darto"), dan pesan WhatsApp asli.
  Harga/testimoni di situs masih contoh menurut README repo.
